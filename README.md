# 🎓 Student Registration & Result Portal

A responsive web-based Student Registration & Result Portal that allows students to enter their personal details, select a course, enter subject marks, and calculate their total marks, percentage, and Pass/Fail status dynamically.

## 🌐 Live Website

[View Live Website](https://jasminecse21.github.io/Student-registration-result-portal/)

## ✨ Features

- 📝 Student registration form
- 👤 Enter student name and register number
- 📧 Email validation
- 📱 Mobile number input
- 🏫 Department selection
- 📚 Course selection
- 📊 Enter subject marks
- 💻 HTML marks
- 🎨 Bootstrap marks
- ⚡ JavaScript marks
- ➕ Automatic total marks calculation
- 📈 Automatic percentage calculation
- ✅ Automatic Pass/Fail status
- 📋 Dynamic student details display
- 📄 Dynamic result table
- 🔄 Calculate Result and Clear buttons
- 📱 Responsive design for mobile and desktop
- 🎨 Bootstrap 5 responsive UI
- ⚡ JavaScript DOM manipulation and form validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 🎯 Purpose

The purpose of this project is to provide a simple and responsive platform where students can register their details, enter examination marks, and dynamically view their total marks, percentage, and Pass/Fail status.
